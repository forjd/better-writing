## What's New in v2.4.0 🎉

We're excited to share some amazing updates!

- **Dry Run Mode:** A new --dry-run flag has been added to allow users to be able to preview changes without applying them.
- **Better Errors:** Error handling has been significantly enhanced — invalid config.toml files now cause the tool to exit with code 2 rather than crashing.
- **Performance:** Various improvements have been made under the hood to elevate the overall experience.
